# Modelo del Constructor de Sesiones

Cada elemento de `session` conserva:
- `id`: identificador del juego del repositorio.
- `phase`: Sin asignar / Calentamiento / Parte principal / Vuelta a la calma.
- `minutes`: duración editable.
- `grouping`: agrupamiento.
- `note`: variante u observación.

La sesión guarda además nombre, fecha, grupo, número de alumnos, duración prevista,
agrupamiento general, objetivos, competencias/criterios y observaciones/adaptaciones.

El botón **Organizar por fases** propone una secuencia inicial; el profesor puede modificarla.
